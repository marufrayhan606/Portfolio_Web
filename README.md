# Md. Maruf Rayhan — Portfolio

A multi-page portfolio for Android development and a growing focus on data science and machine learning. Built with the Next.js App Router, React, TypeScript, and CSS.

## Run locally

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Create a production build with `npm run build` and serve it with `npm start`.

## Pages

- `/` — introduction, portrait, selected projects, and direction.
- `/work` — selected project notes and the rest of the supplied project list.
- `/about` — skills, education, semester results, and achievements.

Update the editable facts in `data/portfolio.ts`. Unknown project roles, stacks, and public links are omitted until confirmed. The portrait in `public/images/maruf-rayhan.jpg` is a color-balanced crop of the supplied photo; the original image is unchanged.
