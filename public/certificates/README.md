# Certificates & Awards Asset Directory

Place your certificates, awards, and event credentials in this folder.

Recommended naming:
- `codetrap-2024.jpg` (CodeTrap 2024 8th Place)
- `data-science-summit-2024.jpg` (4th National Data Science Summit 2nd Runner-Up)
- `data-science-summit-2026.jpg` (5th National Data Science Summit 6th Place)
- `icpc-2023.jpg` (ICPC Preliminary Participation)
- `nasa-space-apps-2024.jpg` (NASA Space Apps Challenge)

Supported formats: `.jpg`, `.png`, `.webp`, `.svg`, `.pdf`
